# 📚 Документация проекта UTSK Intelligent Sales

## 🌐 Архитектура веб-приложения

- **Бэкенд:** FastAPI (модульная архитектура роутеров в `utsk_web/backend/app/`)
- **База данных:** PostgreSQL (`bd_intelligent_sales`)
- **Фронтенд:** Vanilla JS / HTML5 / Chart.js / Tailwind CSS (`utsk_web/frontend/static/`)
