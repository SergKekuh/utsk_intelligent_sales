# UTSK Intelligent Sales — Обзор проекта

## 📌 Общая информация
- **Компания:** ООО «ЮТСК» (Південтрансбудкомплект / ПівденТрансБудКомплект)
- **Версия:** v7.5
- **Назначение:** Корпоративная B2B аналитическая платформа продаж металлопроката и трубной продукции, RFM/ABC-сегментация, анализ оттока и возврата клиентов, матрица отраслей и AI/ML-рекомендательная система допродаж.
- **Токен авторизации:** `utsk2026` (передается через GET-параметр `?token=utsk2026`)
- **Порт сервера:** 5000 (хост `0.0.0.0`)
- **Базовый URL:** `http://localhost:5000/?token=utsk2026`

## 🛠 Технологический стек
- **СУБД:** PostgreSQL 14+ (база данных: `bd_intelligent_sales`, пользователь: `postgres`, пароль: `root`)
- **Бэкенд:** Python 3.10+ (в окружении venv используется Python 3.14), **FastAPI**, **SQLAlchemy** (Session + Raw SQL/Stored Procedures Execution), **Uvicorn**
- **Фронтенд:** Vanilla JavaScript (ES6+), HTML5, CSS3, **Chart.js** для интерактивных графиков, FontAwesome 6, шрифты Inter и JetBrains Mono
- **Архитектура аналитики:** Тяжелые агрегации, RFM-сегментация, парсинг типоразмеров труб и ранжирование рекомендаций вынесены на уровень хранимых процедур PostgreSQL (118 функций), FastAPI выполняет роль легковесного асинхронного API-шлюза.

## 🧭 Ключевые модули платформы

1. **Главный дашборд (`index.html` / `/`)**
   - Верхние KPI: общая выручка, выручка 30 дней, активные 30д/90д, общий чек.
   - Воронка клиентов (RFM) и график динамики выручки по месяцам.
   - Топ-10 клиентов месяца и список клиентов под риском оттока.

2. **Аналитика отраслей и направлений (`directions-analytics.html`)**
   - KPI блока направлений: общая выручка, активные клиенты, накладные, средний чек, отрасль-лидер.
   - Долевой пай-чарт распределения выручки.
   - Помесячная динамика по топ-5 отраслям.
   - Сводная матрица всех 16 отраслей со сравнительными метриками.
   - 5 специализированных подстраниц аналитики направлений: выручка, клиенты, накладные, средний чек, лидеры.

3. **Карточка и аналитика клиента (`client-detail.html` / `/client-detail?code=...`)**
   - Детальный профиль клиента: реквизиты, статус, динамика за 3 года (2024-2026).
   - История накладных с разбивкой по месяцам и позициям (`/client-month-analytics`).
   - Номенклатурный профиль закупок и динамика цен.
   - Блок умных рекомендаций (ML Recommendations) с модальным окном детализации по типоразмерам.

4. **Модуль сегментации клиентов (7 страниц)**
   - Генеральная сегментация (`general-segmentation.html`)
   - Сводная матрица сегментации (`consolidated-segmentation.html`)
   - Повторные клиенты (`repeat-segmentation.html`)
   - Сегмент C2 — стратегические клиенты (`c2-segmentation.html`)
   - Новые клиенты (`new-clients-analytics.html`)
   - Вернувшиеся клиенты (`returned-clients-analytics.html`)
   - Спящие и ушедшие клиенты (`inactive-clients-analytics.html`)

5. **Продуктовая аналитика и типоразмеры труб (`product-analytics.html`)**
   - Вкладка 1: Drill-down по всем типоразмерам (круглые `round_DxS`, профильные `prof_AxAxS`, `prof_AxBxS`).
   - Вкладка 2: ABC-анализ товарной матрицы.
   - Вкладка 3: Динамика 2026 vs 2025 по товарным группам.
   - Вкладка 4: ML-рекомендации с возможностью симуляции и фильтрации остатков склада.
